Website chat widget

Lot Chat

Give a dealership with an existing website a way to capture inventory questions and test-drive requests.

Compare plans ↗View platform screens ↓

Inside the platform

Select a screenshot to inspect the controls at full size. Screens use demonstration inventory and shopper records.

Add an inquiry desk to the website you already have

A dealership can try conversational lead capture before deciding whether to migrate its website. Start with a stock question that a shopper asks often and make sure the person following up receives enough information to answer it.

What the website manager should test

Place the widget through the existing site provider’s installation process. On a sample listing, submit a question containing the stock number and example callback details. Confirm the team can retrieve those details from the agreed lead destination for that installation.

Agree on what the widget can read

Identify the existing website platform and approved inventory source. Work through whether a listing provides a usable stock number or whether the shopper will need to say or type it.

Choose the placement

Test the entry point against mobile navigation, cookie controls and the site’s existing contact buttons. Staff should be able to explain how a shopper opens and closes it.

Check the receiving side

Submit a realistic question about an actual unit. Inspect the dealership, stock reference and callback details in the agreed destination and assign a person to respond.

Questions dealers ask

Will the widget take over navigation on our current site?

The shopper controls navigation on a third-party website. Guided navigation between supported pages is a feature of the hosted showroom.

Can we add phone coverage later?

Yes. Review phone-only and combined phone and widget packages on the pricing page, then plan a call-routing test with the dealership.

Try an existing vehicle page

Bring your current website address and a stock number. We can examine where a shopper opens chat and what context should appear in the staff handoff.
